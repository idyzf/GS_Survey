# Genomics Software Survey

Pesquisa acadêmica e anônima sobre o desenvolvimento de software em genômica e
bioinformática, criada para um TCC de MBA.

O participante escolhe uma equipe (bioinformática, engenharia de software, ciências
biológicas, genética clínica, produto ou outra área) e responde 17 perguntas. Cada
resposta soma pontos para a sua equipe em um placar ao vivo.

**Acesse:** https://idyzf.github.io/GS_Survey/

## Destaques

- Questionário bilíngue (português / inglês) com hélice de DNA em 3D e brasões por equipe
- Placar entre equipes calculado a partir das participações reais
- Respostas salvas em uma planilha Google e enviadas por e-mail à pesquisadora

## Tecnologias

React, TypeScript, Vite, Tailwind CSS e Three.js no front-end, publicado no GitHub Pages;
Google Apps Script e Google Sheets no back-end.
